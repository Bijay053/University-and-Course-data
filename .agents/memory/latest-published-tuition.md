---
name: Latest published tuition
description: Product requirement to choose the latest published applicable international fee.
---

The user requires fees to be extracted from the latest published year, not an older fee.

**Why:** The user explicitly said “always extacted latest fee” after an older international amount was selected from a multi-year course page.

**How to apply:** Keep each price paired with its own year, audience, course and fee period. Choose the latest year with an actual published applicable amount, not the first or largest price. A future intake without a published fee is not evidence for a new amount or for relabelling an old amount.
